# Portable instructions and preserved evidence

20 November 2026: the current README HOST path uses checkout-relative files and no private host paths. Native guides use operator-supplied external paths/variables; those are prerequisites, not execution authority.

Historical raw receipts, logs, hashes, pins and dated lab reports remain byte-exact. They may contain old machine-local paths which are neither download links nor reusable commands. We did not rewrite them, reseal evidence or rewrite Git history to make publication appear clean. Generated EDU pages are projections of their canonical source, not new receipts.

[Residual path inventory](immutable-path-inventory.json) lists file names and SHA256 hashes, without republishing path values. This is an inventory, not a guarantee of absence of every private identifier. Historical native tools may encode operator-specific paths and are not a portable HOST entry route.
